## 开始制作

1. 下载并解压安装包。应看到 `shiyi-dynamic-pet/SKILL.md`、`references` 和 `scripts`。在 Codex 中选择解压后的目录作为当前项目。
2. 将以下指令发给 AI：

> 请帮我安装当前目录里的“十一动态宠物”（shiyi-dynamic-pet）。
> 先检查当前 Codex 版本支持的安装入口，保留完整 Skill 文件夹。
> 优先在当前项目安装；需要供多个项目使用时，先说明用户级安装位置。
> 如果已有同名旧版，先保留旧版和我的改动，再更新。
> 安装后检查能否调用、读取参考素材、使用绘图工具和保存成品。
> 依赖缺失时说明用途、影响、磁盘占用及是否必需，再协助处理。
> 不要删除照片或已有作品，不修改账号设置。
> 另外检查当前是否提供宠物功能、官方 Work Pets 工具和图像生成能力。缺少功能时先说明，不开始上传或替换。

**检查安装：**Skill 能调用，所需工具确实可用。包内本地工具需要 Python 3.10 以上和 Pillow；格式验证另需 PyYAML。官方工具不随此包复制。

安装位置按当前官方文档与实际宿主核对。原 v1.0.0 ZIP 中的旧安装说明提到 `~/.codex/skills/`；本次保留原包字节，新增教程按当前官方用户目录 `~/.agents/skills/`、项目目录 `.agents/skills/` 说明。[查看官方来源与处理方法](安装与常见问题.md)

3. 上传授权照片，说明脸型、发型、神态和动作需求，可以复制：

> 使用十一动态宠物，先检查当前环境，再用这张已授权照片制作完整人物动态宠物，保留脸型、发型与神态。给我小尺寸、浅深背景和动作预览，保存成品与检查记录，先不替换当前宠物。

4. 查看小尺寸、浅深背景和完整动作预览。人物是否像、动作是否连贯、有无闪烁或裁切，需要实际观察；有问题按具体动作返修。
5. 通过检查后，明确要求使用这份新宠物。让 AI 分别核对创建、选中和软件中实际显示；保留原宠物与旧素材。

**完成标准：**预览、动作检查、创建、选中和实际显示分别核对。没有看到软件中的真实显示，继续保留“显示未验证”。

## 遇到问题

没有宠物功能：检查账号、软件版本与当前环境，不把安装 Skill 当成获得平台权限。

选中了但看不到：让 AI 核对目标账号、当前角色和宿主实际显示设置；开关名称以当前界面为准。

动画不连贯：指出具体动作、时间点或帧，再返修受影响的部分。保存失败记录，不用静态截图代替动画检查。

公开反馈前隐去私人照片、账号信息与密钥。使用及公开展示人物素材前，分别确认授权范围。
