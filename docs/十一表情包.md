# 十一表情包 v1.0.0

用本人或已授权人物照片制作漫画聊天表情，支持静态图、动态 GIF 和按编号返修。

[返回资源首页](../README.md) · [安装与常见问题](安装与常见问题.md)

**开始前：**需要电脑 AI 工具能读取文件、参考照片绘图、保存成品。动态 GIF 另需本地执行能力。完整流程已有 macOS Codex 记录，其他宿主和独立使用者尚未完成全流程验收。模型订阅与绘图用量另备。

## 开始制作

1. 下载 ZIP 并解压。应看到 `character-sticker-studio/SKILL.md`，以及 `scripts`、`references`、`assets` 和 `examples`。保留整个文件夹。
2. 在电脑 Codex 中将解压后的文件夹选为当前项目。把这段话发给 AI：

> 请帮我安装当前目录里的“十一表情包”（character-sticker-studio）。
> 先检查当前 Codex 版本支持的安装入口，保留完整 Skill 文件夹。
> 优先在当前项目安装；需要供多个项目使用时，先说明用户级安装位置。
> 如果已有同名旧版，先保留旧版和我的改动，再更新。
> 安装后检查能否调用、读取参考素材、使用绘图工具和保存成品。
> 依赖缺失时说明用途、影响、磁盘占用及是否必需，再协助处理。
> 不要删除照片或已有作品，不修改账号设置。

**检查安装：**让 AI 确认 Skill 可调用、内置画风参考可读、绘图功能可用、文件能保存。GIF 导出还需检查 Node.js（最低 20.9.0）和 sharp 0.35.4。依赖检查通过仍需实际看图。

3. 上传有使用许可的照片，说明所需表情、文字、数量，以及静态或动态要求。可以复制：

> 使用十一表情包，用这张已授权照片制作“你好、收到、谢谢、晚安”四张静态聊天表情，保留脸型、发型和主要配饰。给我可预览、可下载的成品，检查人物辨识度和文字。

完整 v1.0.0 的内部制作流程可能先确认人物形象或动作；这是制作检查步骤，下载获得的是完整包。需要 GIF 时说明动作和循环要求。

4. 看成品的人物特征、配饰、画风和文字，打开每份文件检查。返修时直接说：

> 只修改第 3 张，把笑容改自然，保留已确认的人物、画风、服装和配饰。保留旧版，再交付检查过的新版本。

**完成标准：**能预览、下载并打开成品；动态文件确实会动，循环和边缘正常。加入微信个人表情后再实际发送一次检查。正式公开投稿需另核对当期平台规则；没有审核通过承诺。

## 遇到问题

没有绘图能力：先让 AI 说明所用环境缺少哪个工具，具备绘图条件后再制作。只有本地导出工具时可处理已有帧。

人物或复杂头纱不准确：给出具体编号、部位和期望，必要时补一张更清楚的授权照片。

找不到 Skill 或导出失败：按 [安装与常见问题](安装与常见问题.md) 检查。公开反馈只提供必要信息，隐去照片、账号凭证和密钥。
