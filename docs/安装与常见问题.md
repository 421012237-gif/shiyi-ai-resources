# 安装与常见问题

[返回资源首页](../README.md) · [十一表情包](十一表情包.md) · [十一动态宠物](十一动态宠物.md)

## 下载后从哪里开始

1. 在首页点对应项目的 ZIP 下载链接，保存到电脑。浏览器弹出保存提示时选择自己的项目文件夹。
2. 解压。表情包应有 `character-sticker-studio` 文件夹；宠物应有 `shiyi-dynamic-pet` 文件夹。确认文件夹内有 `SKILL.md`，保留其他配套文件。
3. 在 Codex 中将解压目录选为当前项目，让 AI 能读取文件；复制项目教程中的安装指令。
4. 让 AI 明确回复能否调用、绘图、运行所需工具和保存成品。检查通过后再上传授权照片开始制作。

手机可以阅读与下载，本资源需要在符合条件的电脑 AI 环境安装和制作。

## Codex 的当前安装位置

2026-10-04 实际读取的 [OpenAI 官方技能说明](https://developers.openai.com/codex/build-skills) 列出：

| 位置 | 适用范围 |
| --- | --- |
| 当前项目的 `.agents/skills/` | 供该项目使用，默认优先 |
| 用户目录的 `~/.agents/skills/` | 供该用户多个项目使用 |

由 AI 按当前软件版本确认入口，将完整 Skill 文件夹放入对应位置。首次使用不必自己操作隐藏文件夹。官方说明 Codex 会自动发现新增技能；没有出现时再按指引重新启动。

已安装的旧目录先保留，避免同名技能出现多份导致调用不清楚。新目录说明不代表已在所有软件或设备实测。不同宿主采用各自实际支持的导入方法。

## 点下载却看到 GitHub 文件列表

点首页标明“下载完整包”或“下载安装包”的链接。Releases（版本下载区）中，展开 Assets，选择名称中带项目名和版本的文件。

`Source code (zip)` 和绿色 Code → Download ZIP 下载的是资源库说明；安装请下载 `shiyi-stickers-v1.0.0.zip` 或 `shiyi-pet-v1.0.0.zip`。

GitHub 下载附件采用简短英文文件名以保持链接稳定；页面按中文名称标明用途，两个制作 ZIP 的内容与原发布包逐字节一致。

公开 GitHub 资源可在未登录状态下载。GitHub 访问和下载速度受当前网络影响；可按 [飞书知识库](https://m1egimm0cix.feishu.cn/wiki/WXoHwvxv3icBH5kUq4gcQeKonXe) 标明的版本获取其资源，不把两处不同版本当作同一文件。

## 安装成功，为什么还不能制作

Skill 是工作说明和工具文件。制作还需要当前环境确实能读取照片、参考图绘制、运行工具并交付文件；宠物另需对应功能与官方工具。模型订阅、绘图用量和依赖分别检查。

## 快速开始与原包说明有差异

新 TXT 和 GitHub 教程为 2026-10-04 的导航与安装说明修订。两个制作 ZIP 保留原发布版本和字节：表情包为既有完整 v1.0.0，宠物为飞书当前 v1.0.0。本轮没有改制作逻辑或新增功能验收。

宠物原说明的旧安装路径以本页当前官方来源和实际宿主检查为准；包内许可、素材范围和制作检查仍有效。

## 更新与反馈

主动下载新版，先保留旧版、个人改动和已生成作品。本下载页不会自动更新电脑中已安装的 Skill。

可复制给当前 AI：

> 我用___软件，系统___，Skill 版本___，卡在___步，报错___，希望得到___。请先检查原因，保留我的文件，再给出能验证的处理步骤。

工具问题可 [提交 GitHub 问题](https://github.com/421012237-gif/shiyi-ai-resources/issues/new/choose)。只提供必要报错；照片、密码、验证码、API 密钥和私人资料不要公开。暂不承诺固定响应时效。
